# 来源与许可

- 小说国家名称、设定和疆域编辑来自 Meauzeek 的《随星录》地图项目。来源仓库：<https://github.com/Meauzeek/SOW>，基准提交见 `data/manifest.json`。
- 现实海岸线、行政区划底稿和多数现实城市点位，沿用完整版采用的 Natural Earth 等来源。架空边界经项目修改，不等同于 Natural Earth 原始国界。Natural Earth 数据为公共领域：<https://www.naturalearthdata.com/about/terms-of-use/>。
- 本版不收录照片、旗徽图件、地形栅格、字体文件，也不包含这些资源的 Base64 编码。
- 浏览器地图使用 D3 与 d3-geo-projection，本地附带发行文件；许可分别见 `vendor/LICENSE-d3` 和 `vendor/LICENSE-d3-geo-projection`。
- 未赋予作者世界观资料额外的开源许可；作者保留其原创资料的权利。D3 的许可仅适用于相应第三方程序。
