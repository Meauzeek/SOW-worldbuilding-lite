# 世界观设定说明

本仓库记录《随星录》的架空地球世界。海陆与现实接近，主权边界、国家名称、城市名称和部分城市规模存在显著差别。现实国家或城市名称只是原型线索，不能替代记录中的小说名称或归属。

## 数据的层次

- `data/countries.json` 和 `data/cities.json` 是当前文字资料；每条记录有稳定 ID。
- `docs/countries/` 提供同一批资料的 Markdown 版本，便于 AI 阅读。
- `data/boundaries.geojson` 与国家 ID 对应，保留已编辑的架空疆域。边界仍是地图项目的当前版本，并不表示每个细小边界都已经作者逐点确认。
- 人口、GDP、寿命等包含自动初始化的创作估算。`demographics` 保留其口径、方法或置信度。作者明确指定的个别数据与预设数值并存。
- 国家的人口和 GDP 是国家层面的设定，不能直接用已收录城市求和替代。`includeInNationalTotals: false` 表示城市不计入城市汇总。

## 已明确的关键设定

- 泛南联邦英文为 **Commonwealth Pan-Australis Polaris（CPAP）**；本地称呼 **ᓄᓇᓛᓐ（Nunalaan）**，语言为作者构造的 Inukulaanski。
- 泛南首都是 **茹兰市（Joinanza）**，全称茹安维尔—埃斯佩兰萨自由市，人口 **1200 万**。自由市身份不妨碍它担任首都。
- 阿卡迪亚全称 **États-Unis d'Arcadie（EUA）**，使用英法双语。格陵兰、加拿大北极群岛属于阿卡迪亚；夏威夷是其海外领地而非州。
- 安克雷奇自由市由阿卡迪亚管辖，地理上位于露西亚属阿拉斯加。
- **朗拉空马（Langla Gongma，ལང་ལ་གོང་མ）** 属宋国，是人口 **1.1 亿**的反常巨型城市，默认不计入国家汇总。
- **基托伍（Kitovu）** 位于维多利亚湖西岸，是扎伊尔尼亚首都。
- **新加坡是独立自由市**；马来亚首都仍是吉隆坡。
- 努珊塔拉已迁都至同名新都；最大都市仍是椰城（雅加达）。
- 塞浦路斯是独立国家。非洲以作者有标注的地图为基准；部分未标注国家采用历史地域预设，但不是殖民地。
- 因弗墨累属泛南，位置在现实澳大利亚 Wellington 一带；阿德莱德属于澳大拉西亚。因弗卡吉尔位于泛南属南岛范围，基督城属于澳大拉西亚。
- 宋国汉语地名优先古称或别称，外文通常采用威妥玛式；民族地区优先其原有名称。例：沪渎 / Hu-tu、会宁府对应现实哈尔滨、青城对应呼和浩特、濠镜 / Macau、搭篝 / Takau。现实原型记录在 `realName`，不应直接覆盖小说地名。

## 单位与坐标

- `population`：人数。
- `gdpHundredMillionUSD`：亿美元。
- `coordinates`：`[经度, 纬度]`，WGS84。
- `countryId`：城市管辖国家；`hostCountryId`：若存在，表示自由市地理所在国家。
- `parentId`：属地的上级归属。
- `capitalRole: regional` 表示地区首府，不是独立国家首都。
- `featured`：小说中的重要地点标记。

保留的小说海平面时间线为 1986 年 0 m、2025 年 +3.7 m、2039 年 +5.03 m。最后一项是既有线性情景推算，不是现实气候预测。本版没有高程数据，也不执行淹没分析。

本仓库未包含人物档案、完整小说正文或所有政治制度资料；不能据此假定这些内容已经收录。
